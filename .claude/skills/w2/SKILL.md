# W2 — 회신 공문 작성

수신 공문을 파싱해 회신 시행문 또는 내부결재를 만드는 고정 순서 체크리스트. **규칙의 권위는 프로젝트 CLAUDE.md.** 각 단계를 todo로 만들어 순서대로 수행한다.

## 절차

1. **파싱**: 수신 공문을 kordoc으로 파싱 → 요지·요청사항·회신기한·**제출 방법** 추출. kordoc 불가 시 `text_extract.py --format markdown` 폴백(보고에 'kordoc 미사용' 명시). 개인정보가 보이면 즉시 사용자에게 처리 방침 확인.
2. **분기 — 제출 방법 기준**:
   - 공문 회신 지정 → **회신 시행문(변형 A)**
   - 시스템·메일 제출 → **내부결재(변형 B)**
   골격은 `knowledge/templates/본문-제출회신.md`.
3. **인용**: 본문 `1. 관련:`에 원 공문 문서번호·**시행일**(결재일과 다를 수 있음)을 받은 원문에서 확인해 인용, `scripts/related_lookup.py --doc <번호>`로 대조. 못 찾으면 임의 기입 금지·사용자에게 질문 (received/도 비어 있으면 원본 요청).
4. **이후 w1 절차 3~8과 동일** — 초안 사용자 확인 → 생성 → Validator 1~9 → `output/`+OneDrive 동시 저장 → 검토 요청("발송 전 한글로 열어 확인해주세요") → `log_review.py --type W2` 기록·환류. 회신기한이 있으면 보고에 기한을 명시한다.
